# وعد

تطبيق دردشة صوتية اجتماعية (غرف صوتية مباشرة + اقتصاد هدايا افتراضية)، يستهدف السوق الإماراتي أولًا مع خطة توسع لاحقة للسعودية ومصر.

## البنية

```
mobile/   تطبيق React Native (Expo) — واجهة المستخدم
server/   خادم Node.js/Express — API، إدارة الغرف، المحفظة، الهدايا
```

## التشغيل محليًا

### الخادم
```bash
cd server
npm install
cp .env.example .env   # عدّل DATABASE_URL ليشير لقاعدة بيانات PostgreSQL لديك
psql "$DATABASE_URL" -f src/db/schema.sql   # مرة واحدة فقط، لإنشاء الجداول
npm run dev   # يعمل على http://localhost:4000
```

### التطبيق (Expo)
```bash
cd mobile
npm install
npm start
```

⚠️ **تنبيه:** بعد إضافة `react-native-agora` (يحتوي كودًا أصليًا/Native)، **Expo Go العادي لم يعد يعمل** لتجربة الصوت. تحتاج بناء نسخة تطوير مخصصة عبر [EAS Build](https://docs.expo.dev/develop/development-builds/introduction/):
```bash
npx eas-cli build --profile development --platform android
```
(يتطلب حساب Expo مجاني). الشاشات غير المتعلقة بالصوت (تسجيل الدخول، قائمة الغرف) تعمل بـExpo Go العادي كالمعتاد.

## القرارات المعتمدة لهذه النسخة

| القرار | الاختيار |
|---|---|
| النطاق | اقتصاد هدايا كامل (عملات، هدايا، سحب أرباح) |
| الدول المستهدفة | الإمارات أولًا → السعودية → مصر (تدريجيًا، ليس دفعة واحدة) |
| بوابة الدفع | PayTabs (حساب إماراتي، لا يوجد ترخيص/شركة مسجّلة بعد) |
| بنية الصوت اللحظي | Agora.io (لم تُربط بعد) |

## الخطوة التالية

تسجيل شركة إماراتية ثم فتح حساب PayTabs تجاري — بالتوازي مع تطوير الميزات أعلاه.
