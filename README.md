# وعد

تطبيق دردشة صوتية اجتماعية (غرف صوتية مباشرة + اقتصاد هدايا افتراضية)، يستهدف السوق الإماراتي أولًا مع خطة توسع لاحقة للسعودية ومصر.

## البنية

```
mobile/   تطبيق React Native (Expo) — واجهة المستخدم
server/   خادم Node.js/Express — API، إدارة الغرف، المحفظة، الهدايا
```

## التشغيل محليًا

### الخادم
```bash
cd server
npm install
npm run dev   # يعمل على http://localhost:4000
```

### التطبيق (Expo)
```bash
cd mobile
npm install
npm start
```
امسح رمز QR بتطبيق Expo Go على هاتفك لتجربة الواجهات الحالية مباشرة.

## القرارات المعتمدة لهذه النسخة

| القرار | الاختيار |
|---|---|
| النطاق | اقتصاد هدايا كامل (عملات، هدايا، سحب أرباح) |
| الدول المستهدفة | الإمارات أولًا → السعودية → مصر (تدريجيًا، ليس دفعة واحدة) |
| بوابة الدفع | PayTabs (حساب إماراتي، لا يوجد ترخيص/شركة مسجّلة بعد) |
| بنية الصوت اللحظي | Agora.io (لم تُربط بعد) |

## الخطوة التالية

تسجيل شركة إماراتية ثم فتح حساب PayTabs تجاري — بالتوازي مع تطوير الميزات أعلاه.
